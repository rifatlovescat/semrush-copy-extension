# Changelog

All notable changes to **Semrush Quick Copy** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.2.2] - 2026-10-26

### Added
- **Direct CSV File Download**:
  - Clicking the **CSV** button in the on-page floating widget or the extension popup now immediately downloads a `.csv` file directly to your downloads folder (`<query>_kgr_keywords.csv`).
  - Added UTF-8 Byte Order Mark (`\uFEFF`) so downloaded CSV files open cleanly in Excel, Google Sheets, and LibreOffice without character garbling.
  - Included toast status feedback: `?? Downloaded 10 keywords as CSV!`.

---

## [1.2.1] - 2026-10-26

### Fixed
- **Filter Out Header "Select all keywords" Row**:
  - Eliminated spurious first row generated by Semrush's master checkbox header (`Select all keywords`).
  - Added strict table header & column header exclusion (`[role="columnheader"]`, `[data-testid="table-cell-head"]`, `.sm-table-layout__header`).
  - Removed accidental `[data-ui-name="Checkbox.Text"]` selector and added an explicit regex filter against `select all` / `keyword` control strings.
  - Automatically prunes any stale `kgr_select all keywords` entries from local extension storage.
  - Robust KGR division formula updated to `=IF(AND(E2<>"", C2>0), ...)` to guarantee zero `#DIV/0!` errors.

---

## [1.2.0] - 2026-10-26

### Added
- **KGR (Keyword Golden Ratio) Integration**:
  - Exact column format: `Keyword | Intent | MSV | KD | ALLINTITLE | KGR | CPC | Comp | Updated`.
  - **Live Google Sheets Formula**: Injected formula `=IF(ISNUMBER(E2), ROUND(E2/C2, 4), "")` for immediate auto-calculation in Google Sheets.
  - **KGR Cell Dynamic Color-Coding**:
    - `KGR < 0.25`: Soft Green (`#E6F4EA` / `#137333`) - ? Golden / Easy
    - `0.25 <= KGR <= 1.00`: Soft Yellow (`#FEF7E0` / `#B06000`) - ? Moderate
    - `KGR > 1.00`: Soft Red (`#FCE8E6` / `#C5221F`) - ? Hard
- **Google Search allintitle Auto-Grabber (`google_content.js`)**:
  - Automatically runs on `google.com/search?q=allintitle:...`.
  - Extracts the exact result count from Google's `#result-stats` (e.g., `About 174 results`).
  - Automatically caches the count to `chrome.storage.local` and displays an on-page confirmation toast badge.
- **? Auto-Check KGR Button**:
  - Added directly into the on-page floating widget and popup.
  - Sequentially queries Google with safe delay to populate allintitle counts automatically.
- **1-Click Hyperlinks**:
  - Pre-fills unchecked allintitle cells with direct Google search formulas: `=HYPERLINK("https://www.google.com/search?q=allintitle:%22"&A2&"%22", "?? Check allintitle")`.

## [1.1.0] - 2026-10-26

### Added
- **Rich Styled HTML Clipboard Copying**: Direct 1-click paste into Google Sheets & Excel with full styling (zero Apps Script required).
- **Semrush KD% Heatmap Colors**: Automated color-coding for Keyword Difficulty:
  - `0 - 29`: Soft Green (`#E6F4EA` / `#137333`) - Very Easy
  - `30 - 49`: Soft Yellow (`#FEF7E0` / `#B06000`) - Possible
  - `50 - 69`: Soft Orange (`#FEEDDC` / `#C05621`) - Difficult
  - `70 - 84`: Soft Red (`#FCE8E6` / `#C5221F`) - Hard
  - `85 - 100`: Dark Red (`#F8D7DA` / `#721C24`) - Very Hard
- **Color-Coded Intent Badges**: Informational (Blue), Commercial (Amber), Transactional (Red), and Navigational (Purple).
- **Deep Purple Styled Header Row**: `#2B0F52` background with bold white text and cell borders (`#D2D6DC`).
- **Shadow DOM Encapsulation**: Isolated floating widget inside `attachShadow({ mode: 'open' })` to prevent any CSS style inheritance or padding leakage from Semrush.
- **Repository Tagging & Project Metadata**: Added `package.json` with metadata, tags, and version tracking.

### Fixed
- **SVG Disabled Detection Bug**: Fixed an issue where Semrush's internal `<svg disabled="" ...>` icons triggered false-positive locked row checks, causing `0 Found` results.
- **Widget Bottom Padding & Spacing**: Eliminated awkward bottom gap and oversized shadow spilling.

### Added
- Initial release of **Semrush Quick Copy** (Manifest V3).
- Real-time DOM scraper for Semrush Keyword Magic Tool (extracts top 10 visible free keyword results).
- Popup interface with live keyword preview cards and metric badges (Volume, KD%, CPC, Freshness).
- Multiple export modes: TSV (Sheets/Excel), CSV, and Keywords Only.
- Direct `.csv` file download.
- Floating in-page quick-action widget.
- Custom deep purple and lavender theme styling.
- Fixed glowing footer linking to [r1fat.pages.dev](https://r1fat.pages.dev).
- High-resolution icon set (16x16, 48x48, 128x128).
